# Privacy Policy

CalmStart does not send user data to developer-operated servers and does not sell or share user data for advertising.

When browser synchronization is available, CalmStart stores its settings and portable layout metadata in the browser-provided extension sync storage (`chrome.storage.sync` or the browser equivalent). This data may be synchronized through the user's browser account provider.

Synchronized layout metadata can include bookmark folder titles and structural references needed to reproduce the column layout on another browser profile. CalmStart does not upload the full bookmark database to a developer-operated service.

Local-only state, including open/closed folder state, locally selected background-image file data, recovery backups and diagnostic metadata, remains in browser-local extension storage and is not intentionally written to the sync area.

On Firefox, website domain names shown by the extension may be shared with the user-selected third-party favicon provider in order to display website icons. This is configurable in the options.
