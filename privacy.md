# Privacy Policy

CalmStart is a customizable browser new tab page. This policy describes the data CalmStart accesses and how that data is used.

## Data CalmStart accesses

CalmStart can access browser bookmarks so it can display bookmark folders and links on the new tab page. Optional features can also display browser-provided most-visited pages, recently closed tabs and tabs from other devices.

CalmStart uses browser extension storage to save settings and layout information. When browser synchronization is available, supported settings and portable layout metadata are stored in the browser-provided sync storage (`chrome.storage.sync` or the browser equivalent) and may be synchronized through the user's browser account provider.

Synchronized layout metadata can include bookmark folder titles and structural references needed to reproduce the chosen column layout on another browser profile. CalmStart does not synchronize the user's full bookmark database itself.

## Local data

Device-specific state, including open/closed folder state, locally selected background-image file data, recovery backups and diagnostic metadata, remains in browser-local extension storage and is not intentionally written to the sync area.

## Developer-operated services

CalmStart does not send bookmark data, browsing data, settings or layout data to developer-operated servers. CalmStart does not use developer-operated analytics or advertising services and does not sell user data.

## Data use and sharing

Data accessed through browser permissions is used only to provide CalmStart's user-facing new tab, customization and synchronization features. CalmStart does not use or transfer user data for personalized advertising, creditworthiness or lending purposes.

CalmStart does not allow humans to read user data except where the user intentionally provides information for support, where required for security or legal reasons, or where otherwise permitted by applicable Chrome Web Store policy.

## Browser provider

If browser sync is enabled, synchronized extension data is handled by the user's browser/account provider according to that provider's terms and privacy practices.

## Firefox favicon provider

On Firefox, website domain names shown by the extension may be shared with the user-selected third-party favicon provider in order to display website icons. This is configurable in the options.

## Changes

If CalmStart's data practices materially change, this privacy policy and the relevant store disclosures will be updated before the changed practices are introduced.
